# 04 - Photo Document Collection

## Purpose

Builds a safe photo and document checklist for storm leads.

## Tags

`demo`, `roofing`, `storm-restoration`, `phase-2`, `claims`

## Inputs

Use `../demo-data/photo-document-checklist.json` as pinned data or manual test input.

## n8n Steps

1. Import `04-photo-document-collection.json`.
2. Pin the sample checklist payload.
3. Execute manually.
4. Confirm the workflow requests ground-level photos, claim-number status, adjuster status, and safety language when needed.
5. If moving to production, connect approved copy and photo-storage links.

## Demo Notes

Do not ask homeowners to climb on roofs. Do not request full claim documents through public forms.
